### ALGO-000181: Continuous Skolem problem
- **Subfield:** Games, automata, and verification
- **Open:** Given rational \(A,x,c\), decide whether \(c^\top e^{At}x=0\) for some \(t>0\), with identically zero cases handled separately.
- **Status:** General decidability remains open; bounded-dimensional and spectral restrictions admit partial results.
- **Type:** theory
- **Why:** Is the continuous-time counterpart of detecting a zero in a recurrence.
- **Key works:** Chonev, Ouaknine, and Worrell (2016), *On the Skolem Problem for Continuous Linear Dynamical Systems* (identifier verify).
- **Related:** Control theory—reachability of linear flows; transcendence theory—zeros of exponential polynomials.
